## SECTION 4 — 주요 사건 상세 보고

### 🔴 CRITICAL [취약점 악용] PHP2Shell (CVE-2026-109618·109619) — 인증 없는 원격 코드 실행

#### 사건 개요
- 누가: 공격 주체 미공개. 복수 보안업체가 악용 시도를 관측했다.
- 언제: PHP 보안 업데이트 2026-10-21(현지), 국내 사이버위기 경보 '주의' 상향 2026-10-22 12:00.
- 어디서: PHP 런타임을 사용하는 웹서비스 전반. 안랩은 취약 버전으로 추정되는 국내 서버를 약 11만 건으로 집계했다.
- 무엇을: PHP의 심각한 취약점 2건. 인증 없이 원격에서 코드를 실행해 웹셸 설치, 고객정보 유출, 홈페이지 변조·마비로 이어질 수 있다고 과기정통부가 안내했다.
- 어떻게: 공개 웹서비스에 대한 요청 처리 중 PHP 결함 악용. Hadrian은 관측된 공격 다수가 세션 업로드 진행(upload-progress) 경로를 악용한다고 밝혔다. 카스퍼스키는 패치 공개 전 악용 시도를 관측했고, 유출된 익스플로잇 도구가 유통 중이라는 보도가 있다. 정부는 가짜 PoC에 악성코드가 숨겨진 경우가 많다고 경고했다.
- 얼마나: 국내 대규모 피해는 공식 확인되지 않았다. 룩셈부르크 금융감독기관(CSSF)은 자국 금융기관의 실제 침해 발표가 없다고 밝혔다. watchTowr는 시도를 관측했으나 성공 사례는 확인하지 못했다.

- 누가: 운영 주체 미공개(ThreatFabric 분석).

# [보고] PHP2Shell(PHP 원격 코드 실행 취약점) 사고 분석 및 대응 리포트

### 1. 사고 개요 및 규모
- 발견 시점: 2026-10-21 (PHP 개발팀 보안 업데이트 공개, 사전 악용 시도는 카스퍼스키가 관측)
- 유출·피해 규모: 확인된 국내 피해 없음. 국내 취약 버전 추정 서버 약 11만 건(안랩 집계). 버전 식별 가능한 인스턴스 중 약 1/3만 업데이트 대상 브랜치 사용(Bitsight)
- 피해 항목: 미공개 (과기정통부 안내상 웹셸 설치, 고객정보 유출, 홈페이지 변조·마비 가능)

### 2. 사고 원인 및 경위
- 공격 유형: 공개 서비스 악용 T1190, 웹셸 T1505.003. 인증 없는 원격 코드 실행. 기술적 원인은 PHP 런타임 결함(CVE-2026-109618·109619). 관리적 원인으로 지원 종료 PHP 버전 잔존과 패치 후 웹서버 미재시작 시 취약 상태 유지가 지적되었다.
- 발견 배경: PHP 보안 업데이트 공개 전부터 악용 시도 관측(Kaspersky), 사전 취약점 번호 유포(비공식 SNS), 유출 도구 유통 보도. 국내는 KISA·과기정통부가 보안 업데이트 권고 및 경보 상향.
- 발생 추정 시점: 조사 중 (악용 시도 관측 시점은 패치 공개 전후, 출처: Kaspersky·SecurityWeek)

### 3. 현재 대응 상황
- 즉시 대응: 정부 비상대응 체계 가동(침해대응 인력 증원, 비상출동조 대기), 가짜 PoC 주의 안내
- 보안 강화: 패치 적용 후 웹서비스 재시작, 패치 불가 시 외부 접속 차단 또는 서비스 일시 중단 권고
- 유관기관 신고: 해당 없음(국내 실제 침해 확인 시 KISA 신고 대상). 룩셈부르크 CSSF는 자국 내 금융기관 침해 발표가 없다고 확인

**비즈니스 리스크**

## 자체검증 결과

① 논리적 비약 여부: 없음. 단, 다음 두 가지를 보정했다. (a) PHP2Shell은 CISA KEV 등재가 확인되지 않아 CRITICAL 근거를 "CVSS 9.2 + 패치 공개 전후 악용 시도 관측 + 고객 채널(웹서비스)에 즉시 중대한 영향 가능"으로 한정했다. (b) 금융권 16개사 건은 계좌·카드번호 미유출, 단일사 최대 2.5만 명이라 CRITICAL이 아닌 HIGH로 분류했다.
② 추측성 표현 여부: 없음. 배후 귀속(라자루스)은 각 보안업체의 평가임을 명시했고 확정 귀속하지 않았다. ARTEX 사용 여부는 공식 조사 진행 중으로 기재했다. 시사점 항목의 시나리오는 모두 "~한 경우" 조건절로 작성했다.
③ 실무 적용 가능성: 적합. 단, 원문 직접 열람이 불가하여 수치·날짜는 검색 결과 기준이므로 시행 전 원문 재확인이 필요하다. 당사 PHP 자산 보유 현황과 CrossWeb EX 설치 여부는 미확인 상태로 조사 항목으로 제시했다.
④ 출처 검증 상태: ✅ 확인 5건 (No.1, 2, 5, 8, 11) / ⚠️ 미확인 7건 (No.3, 4, 6, 7, 9, 10, 12). 금융위·금감원·CISA·KISA·보안업체 원문은 직접 열람하지 못했고 언론·검색 결과를 통해 확인했다. 정부 원문 기준 최고 신뢰도 Tier 1 표기는 해당 기관 발표를 인용한 보도에 근거한다.
⑤ 날짜·기간 기준 검증: KST 기준 2026-10-18~2026-10-24 충족 항목 11건. 예외 1건: No.2 금융권 16개사 침해(최초 공개 2026-10-14, 기간 내 후속 보도 2026-10-22)는 당사 영향도를 고려한 선행 사건 예외 수록. 기간 직전 공개된 BeyondTrust Remote Support 제로데이(CVE-2026-102764, 공개 2026-10-15, CISA KEV 2026-10-16)와 Fortinet FortiMail·Citrix NetScaler·PAN-OS 악용 취약점(2026-10-01~14)은 기간 외로 제외했으며, 미적용 시 별도 패치 점검이 필요하다. CISA 2026-10-23 KEV 추가 1건은 상세를 확인하지 못했다. Tier 1 중 금융감독원·금융보안원·개인정보보호위원회·NIST·ENISA, Tier 2 중 AhnLab ASEC·Mandiant·Unit 42 등은 기간 내 직접 자료를 확인하지 못했다("해당 기간 특이사항 없음" 또는 확인 불가). 랜섬웨어·DDoS·공급망 유형은 기간 내 확인 건 없음.
