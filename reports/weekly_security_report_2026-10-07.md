## 🔴 CRITICAL [취약점 악용] Cisco Catalyst SD-WAN Manager — CVE-2026-76504 인증우회로 관리자 권한 획득

### 사건 개요

**누가** Cisco가 공시했으며 공격 주체는 미공개이다. **언제** 2026-09-30 취약점이 공시되었고 2026-10-01 CISA KEV에 등재되었다. **어디서** Cisco Catalyst SD-WAN Manager(SD-WAN, Software-Defined WAN, 소프트웨어 정의 광역망) API 인증 처리부이다. **무엇을** 비인증 원격 공격자가 조작된 HTTP 요청으로 관리자 권한의 API 접근을 얻을 수 있다. **어떻게** URI 인코딩 처리 오류로 인증 규칙을 우회한다. **얼마나** 구성과 무관하게 전 배포가 영향받고 우회 방안이 없으며, Cisco는 패치 제공 전부터 악용을 인지한 것으로 보도되었다.

### 2. 사고 원인 및 경위

**기술적 원인**

- 공격 유형: T1190 Exploit Public-Facing Application(공개 애플리케이션 악용) — 보도 기반 매핑, 상세 TTP 조사 중. 신한은행은 입력값을 무작위로 대입해 조회한 정황이 보도됨
- 침해 시스템: 신한은행 대출모집인 조회서비스, KB국민은행 직원용 모바일 업무지원시스템, 하나은행 영업지원시스템(ODS). 모두 인터넷·모바일뱅킹과 분리된 업무 시스템
- 발견 배경: 각 사의 비정상 외부 접근 탐지 후 공지·언론 보도 및 금융당국 공유. 일부 언론이 AI 자동화 도구 활용 가능성을 제기했으나 당국이 확인한 사항은 아님

**관리적 원인**

- 핵심 금융거래 시스템 중심의 통제가 비핵심 업무 시스템까지 적용되지 않았을 가능성은 언론에서 지적되었으나, 개별 사의 관리적 원인은 조사 중
- 발생 추정 시점: 조사 중 (2026-09-28 이후 연쇄 발생으로 보도, 비즈워치·뉴데일리 등)

### 3. 현재 대응 상황

- 즉시 대응: 각 은행의 해당 서버·접근 경로 차단, 공격 IP 차단, 예가람저축은행 서비스 일시 중단 및 외부 IP 차단
- 보안 강화: 금융위 12개 항목 체크리스트 기반 전 금융권 자체 점검, 금융당국·은행 간 공격 IP 정보 공유, 과기정통부·KISA 긴급 대응체계 가동 및 CISO 신고기업 약 2만 8천 곳 점검 권고
- 유관기관 신고: 금융감독원 신고 및 현장 조사 진행. 개인정보보호위원회·경찰 조사 여부는 이번 수집 자료에서 확인되지 않음 (조사 중)

### 4. 경영진 제언

**비즈니스 리스크**

- 평판·고객: 유출 정보를 결합한 사칭 피싱이 우려되어 금융당국이 사칭 경보를 발령했으며, 당사 고객의 문의·민원 증가 가능성
